# Changelog

## 2.7.2 — 2026-10-14
- Update progress is reliable: 0–100 % while downloading, then "Preparing…" while the update is checked, instead of sitting at 99 %.
- Installing an update now shows a clear "Installing the update" screen and the installer's progress window; the app reopens by itself.

## 2.7.1 — 2026-10-14
- ADB Connector is now open source under the MIT License.
- Licenses of all included components (scrcpy, adb, FFmpeg, SDL2, libusb and JavaScript libraries) ship with the app — Settings → About → Open-source licenses.

## 2.7.0 — 2026-10-14
- **APK folders**: pick folders with APK files; the newest version of each app appears in My library.
- **App updates**: apps on the device with a newer version in your folders or library get an Update button, and "Update all" updates them in one go.

## 2.6.2 — 2026-10-14
- Switching the language in Settings now applies immediately.

## 2.6.1 — 2026-10-14
- Updates are one click: the app downloads only the changed parts (usually about 1 MB) and restarts into the new version by itself.
- Download progress is shown correctly from 0 to 100 %.

## 2.6.0 — 2026-10-14
- **Hebrew** interface (Settings → Language), with a full right-to-left layout.
- The Devices page explains how to connect phones and tablets (USB and Wi‑Fi) as well as watches.

## 2.5.0 — 2026-10-14
- First installable version: a normal Windows installer with Start-menu and desktop shortcuts.
- Automatic updates from GitHub, with an update button at the bottom left.
- App list shows real app names and icons; a switch shows package names.
- My library keeps every app you install, any version, with one-click reinstall; History lists every install.
